# Marketing
Marketing-Medien von Habibi Reinigung.

- `instagram/`: freigegebene Beiträge und `plan.json` (Veröffentlichungsplan)
- `vorlagen/reel/`: Reel-Baukasten (Motion Design mit Stimme)
- `vorlagen/reel/VIDEO-REGELN.md`: **verbindliche Regeln für alle Videos.** Vor jedem Video lesen.
- `werkstatt/`: Zwischenablage (Audio-Brücke), nichts davon wird veröffentlicht
